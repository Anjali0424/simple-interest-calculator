# Simple Interest Calculator

This project is a simple interest calculator that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Rate of interest
- Time period

## Output

The calculator calculates and displays the simple interest.

## Project Purpose

This project demonstrates a simple Bash-based calculator and basic Git and GitHub workflow.
